# HackGenius 🛡️

An AI-powered ethical hacking assistant that guides users through attack vectors, exploitation steps, and remediation strategies using LLM.

## Tech Stack
- **Backend:** Python, Flask, SQLAlchemy
- **Frontend:** React, Tailwind CSS, Vite
- **AI:** LLM Integration via API

## Features
- AI-guided ethical hacking workflows
- Structured attack vector breakdowns
- Tool recommendations and exploitation steps
- Remediation strategies for vulnerabilities

## Setup

### Backend
```bash
pip install -r requirements.txt
python app.py
```

### Frontend
```bash
npm install
npm run dev
```
